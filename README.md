# Text Analyzer - Engeto Python Akademie Projekt 1

Tento projekt je mým prvním úkolem v rámci **Engeto Online Python Akademie**. Jedná se o jednoduchou konzolovou aplikaci, která:

- Umožňuje uživatelům se přihlásit pomocí pevně daných přihlašovacích údajů.
- Nabízí výběr ze tří textů.
- Pro zvolený text provádí statistickou analýzu slov:
  - Počet slov celkem
  - Počet slov začínajících velkým písmenem (titlecase)
  - Počet slov složených jen z velkých písmen (uppercase)
  - Počet slov složených jen z malých písmen (lowercase)
  - Počet číselných řetězců a jejich součet
- Vytváří jednoduchý textový histogram délek slov.
